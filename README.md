# Patobeur — Game & Creative Developer

Portfolio consacré à mes jeux web et à mon travail sur les systèmes de gameplay, la génération procédurale et la 3D temps réel.

## Projets présentés

- [The Backrooms](https://patobeur.github.io/backrooms/) — exploration procédurale en vue subjective
- [Driver](https://patobeur.fr/patobeur/games/driver/) — conduite arcade, routes générées et trafic autonome
- [LabyCube](https://patobeur.github.io/labycube/) — puzzle et navigation sur les six faces d’un cube
- [BeeStory](https://patobeur.github.io/beestory/) — gestion apicole isométrique

## Technologies

- HTML5 et CSS natif
- JavaScript
- Formspree pour le formulaire de contact
- GitHub Pages pour la publication

## Lancer le site localement

```bash
python -m http.server 8000
```

Ouvrir ensuite `http://localhost:8000/`.
